1阶段一详解：图像编辑

AI 图像生成阶段。输入角色图与参考图，通过弹窗面板中的提示词生成编辑后的 BL 结果图。

文件名规则是否必须说明
图像1.png / .jpg 必须 主输入图（角色图/产品图）。若未提供但有视频文件，软件会自动提取视频第一帧生成。
图像2.png / .jpg 可选 参考图（姿势/服装/背景参考）。提供后进入 双图模式，生成效果更精准。
BL-已完成.png 输出 阶段一完成后的结果图。若已存在，软件自动跳过阶段一。
自动提取机制：如果文件夹内没有 图像1 但有视频文件（如 动作参考.mp4），软件会自动用 ffmpeg 提取视频第一帧保存为 图像1.png，然后继续执行。
阶段一任务规范与流程

任务文件夹名称命名要求：自定义名称（建议短路径且不含特殊字符）

文件命名要求：主输入图必须包含 图像1 关键词；参考图必须包含 图像2 关键词；输出结果自动命名为 BL-已完成.png

任务处理流程：
1. 扫描文件夹，识别 图像1 与 图像2
2. 若检测到 BL 文件，自动跳过阶段一
3. 提取面板提示词参数，提交 AI 图像生成任务
4. 下载结果并保存为 BL-已完成.png

阶段一输出结果： BL-已完成.png
请注意，参考视频首帧与BL-已完成png之间的差异代表视频将被编辑/修改/替换的部分。需确保BL-已完成.png完整出现产品。

阶段二视频编辑阶段完全依赖BL-已完成.png结果（手动输入时名称包含bl或者BL即可）进行应用，参考视频首帧与BL-已完成.png之间的差异代表视频需要被编辑/修改/替换的部分，且建议BL-已完成.png尽量与参考视频首帧保持构图、动作的一致或者相似以保证生成结果。

任务弹窗中的提示词为图像编辑提示词，非视频提示词！即图像1+图像2+提示词→生成BL-已完成png。

2阶段二详解：动作迁移 / 角色替换

将阶段一的角色图（BL）与参考视频的动作进行融合，输出成品视频。参考视频文件名可任意自定义。

文件名规则是否必须说明
BL-已完成.png
（手动提供则名称包含"bl"即可）		 必须 阶段一输出结果图，作为阶段二的角色输入。
任意视频文件名 必须 参考视频，提供动作/姿态/镜头运动。名称自定义，如 动作参考.mp4。软件自动提取其时长用于参数计算。
成品.mp4 输出 阶段二完成后的成品视频。若已存在，软件自动跳过阶段二。
三种模式对比
模式成本/速度适用场景参考视频要求
稳定模式 最低 / 最快 ≤15 秒短视频 必须为人物整体 + 清晰手势。全身镜头最佳。
品质模式 最低 / 最快 复杂运镜 / 分镜切换 / 产品互动 / 动物 / 多人 支持复杂场景，自动分段处理长视频（≤16s 分 3 段，>16s 分 5 段）。
高级模式 最高 / 最慢 近景人物 / 皮肤细节级处理 真实感最强，适合面部特写、皮肤纹理、光影细节要求极高的场景。
时长对齐警告：阶段二生成的成品视频时长，必须与后续阶段三的音频时长匹配（误差 ≤0.5 秒）。若音频更长，视频会被裁剪；若视频更长，音频会被加速（atempo）。
阶段二任务规范与流程

任务文件夹名称命名要求：自定义名称（建议短路径且不含特殊字符）

文件命名要求：角色输入图必须包含 BL 关键词；参考视频文件名可任意自定义，但不可包含 "成品"；输出结果自动命名为 成品.mp4

任务处理流程：
1. 扫描文件夹，识别 BL 文件与参考视频
2. 若检测到 成品.mp4，自动跳过阶段二
3. 自动提取参考视频时长并计算参数
4. 提交动作迁移 / 角色替换 / 视频编辑任务
5. 下载结果并保存为 成品.mp4

阶段二输出结果： 成品.mp4

3阶段三详解：音视频合成

对口型、音色替换、文案替换。可串联阶段二，也可独立运行（纯阶段三）。

3.1 串联模式（接阶段二）

阶段二完成后，若文件夹内存在音频文件，软件自动进入阶段三处理。

文件名必须说明
成品.mp4 必须 阶段二输出视频，作为数字人底片。
p3-音频.mp3 模式一 直接使用音频文件。手动放入时文件名必须包含 p3-音频。
音色参考.mp3 + 文案.txt 模式二 音色参考音频文件名必须包含 音色，配合 UTF-8 编码文案，AI 生成语音后再合成。
成品-p3.mp4 输出 最终成品视频。若已存在则跳过。
音频时长对齐：软件会自动比较成品视频与音频的时长。若视频比音频长 0.5 秒以上，视频会被裁剪；若音频比视频长，音频会被 atempo 加速压缩。无需手动处理。
阶段三任务规范与流程

任务文件夹名称命名要求：自定义名称（建议短路径且不含特殊字符）

文件命名要求：视频底片必须命名为 成品.mp4；模式一直接音频必须包含 p3-音频 关键词；模式二音色参考必须包含 音色 关键词且需配合 .txt 文案；输出结果自动命名为 成品-p3.mp4

任务处理流程：
1. 扫描文件夹，识别 成品.mp4 与音频文件
2. 若检测到 成品-p3.mp4，自动跳过阶段三
3. 判断音频模式：模式一（p3-音频直接合成）/ 模式二（音色+文案先生成语音）
4. 自动对齐视频与音频时长（裁剪或 atempo 加速）<
5. 提交音视频合成任务
6. 下载最终结果并保存为 成品-p3.mp4

阶段三输出结果： 成品-p3.mp4

4数字人模式详解

当文件夹名称包含 数字人 时，软件进入数字人专用识别模式。无需阶段一/二，直接根据素材组合判断任务类型。

四种数字人任务类型
类型输入音频方式说明
图像数字人 ① 角色图 + 音频（名称自定义） 直接使用音频 输入静态角色图 + 完整音频，AI 生成说话的数字人视频。
图像数字人 ② 角色图 + 音色（名称需包含"音色"）+ 文案 AI 生成语音 先按音色和文案生成语音，再合成数字人视频。
视频数字人 ③ 视频底片 + 音频（名称自定义） 直接使用音频 输入已有视频底片 + 完整音频，进行口型同步与音色替换。
视频数字人 ④ 视频底片 + 音色（名称需包含"音色"）+ 文案 AI 生成语音 先按音色和文案生成语音，再对视频人物进行口型同步。
重要：数字人文件夹名称必须包含 "数字人" 三个字，否则软件会按普通三阶段流程识别。同时，数字人任务文件夹内不能出现 "成品" 视频，否则会被识别为已完成而跳过。

软件安装与使用

使用前三项准备

准备项 1
安装位置

选择非C盘安装即可。（若出现 Windows 弹窗选择仍运行即可）

准备项 2
兑换码兑换

首次运行时在弹窗中输入兑换码，兑换码一次有效，仅限一机一码使用

准备项 3
获取 RUNNINGHUB API-KEY

购买会员后获取 API-KEY 并填入软件面板，支持多 KEY 配置提升并行效率

兑换码兑换步骤演示
获取 RUNNINGHUB API-KEY 演示

步骤1：购买 RunningHub 会员 / 积分

必须购买 99 元专业版，建议选择包月 — 可马上取消

购买地址：https://www.runninghub.cn/vip-rights/2

步骤2：获取 API-KEY

购买后复制 API-KEY，地址：https://www.runninghub.cn/enterprise-api/consumerApi

步骤3：填入 API-KEY

注意每个 KEY 支持 3 任务并行（会员限制），也就是最多同时生成 3 个任务。但软件支持配置多个 KEY（也就是开通多个 RunningHub 账户）提高并行数量和批量生成效率。理论上无上限。

运行报错与处理

若软件关闭后无法打开，可检查后台进程是否未正确关闭，强制关闭进程（右键结束任务）后再打开即可。

若软件出现并行报错或者重复出现无法正常提交（如高峰期繁忙或者网络中断），（必须）先清空面板所有任务，并在后台（https://www.runninghub.cn/call-api/call-record）取消在运行任务。请注意，只要任务未生成成功中途取消均不扣费，且再次提交同个批次任务将自动跳过已完成的阶段或任务，不会重复生成造成浪费。
